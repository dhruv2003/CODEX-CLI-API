# Sidecar v1.4.4 — GPT-6 model hotfix

This hotfix adds GPT-6 Sol and GPT-6 Luna to Sidecar's default model catalog. They are available in the setup and connection model pickers and through authenticated model discovery.

## What changed

- Added `gpt-6-sol` and `gpt-6-luna` to the default model list and example configuration.
- Enabled image input for both models, plus `ultra` reasoning for Sol. Luna supports `low` through `max`.
- Updated the bundled Codex CLI to 0.155.0, the minimum version that supports both models.

## Automatic-update support files

You do not need to download `latest.json`, `.app.tar.gz`, `.sig`, `SHA256SUMS`, or provenance files manually. The app downloads and verifies its update automatically. Use the installer links above for manual installation.
