# Sidecar v1.4.3 — brand rename hotfix

Sidecar is the local AI gateway for proving an idea before paying to scale it. This hotfix completes the product rename from Codex CLI API to **Sidecar**, brings the new brand kit into the shipped app, and points customers to [sidecar.co.in](https://sidecar.co.in).

> Pay only for scale, not for POC.

## What changed

- Renamed the desktop app, dashboard, window title, tray label, About screen, installer copy, and documentation to Sidecar.
- Replaced the old product mark with the Sidecar cobalt, charcoal, off-white, and white brand system across the desktop shell, dashboard, and native app icons.
- Added the complete source brand pack under `brand-assets/Sidecar_Brand_Assets_Pack/` so future website and product surfaces use the same assets.
- Updated product-facing links and release metadata to `sidecar.co.in`.

## Compatibility

This is a branding and packaging hotfix. Existing API routes, API key format, workspace behavior, updater feed, updater identifier, and signing identity are unchanged. The source package and desktop crate are now named Sidecar, while the runtime compatibility contracts remain stable. Existing Sidecar installations can update without reconfiguring their local gateway or IDE connection.

The product remains focused on testing proof-of-concepts locally before committing to production infrastructure. IDE connections are supported as a convenience, but the core value is validating what works before paying for scale.
