# Sidecar v1.4.3

This hotfix renames the desktop product and dashboard to **Sidecar** and updates the product website to [sidecar.co.in](https://sidecar.co.in).

## Changed

- Renamed the desktop app, window title, tray label, dashboard, About screen, and installer copy to Sidecar.
- Updated product-facing documentation and connection examples to use Sidecar.
- Kept the existing API routes, API key format, internal package identity, updater identity, and compatibility behavior unchanged.

## Installers

The v1.4.3 release should publish the renamed Sidecar installers while preserving the existing updater feed and signing identity.
