    Personal browser app

    Serve your app over HTTP or HTTPS and add its exact origin in the key’s policy, such as http://127.0.0.1:5500 or http://localhost:3000. The host and port must match.

    Use this in your own app with a key you enter at runtime. Keep the key in memory; do not publish it in shared frontend code. The selected model and reasoning level are included below.

    Supported features & remote clients

    Text chat and streaming are supported. Client tool calls, VS Code Agent mode, and standard image uploads are not supported. Images require custom local-file input. Requests allow 100,000 prompt characters and a 1 MB JSON body.

    No tunnel is needed for local VS Code. The desktop app only supports local connections.

    For SSH, WSL, or containers, localhost refers to that environment. Use an appropriately forwarded endpoint.

    Advanced: restricted HTTPS tunnel

    Expose only authenticated /v1/ routes. Never expose the admin dashboard.
