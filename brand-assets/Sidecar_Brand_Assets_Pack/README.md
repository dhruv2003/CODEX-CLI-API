# Sidecar — Brand Assets Pack

Production-ready logo exports for the Sidecar local AI companion brand.

## Core files

- `svg/sidecar-symbol.svg` — primary symbol, transparent
- `svg/sidecar-symbol-black.svg` — monochrome black
- `svg/sidecar-symbol-white.svg` — monochrome white
- `svg/sidecar-symbol-reversed.svg` — dark-background symbol
- `svg/sidecar-lockup-light.svg` — horizontal lockup, light background
- `svg/sidecar-lockup-dark.svg` — horizontal lockup, dark background
- `svg/sidecar-wordmark-black.svg` / `white.svg` — wordmark-only
- `svg/sidecar-app-icon-light.svg` / `dark.svg` / `blue.svg` — app icon masters

## Raster exports

PNG exports include 1024, 512, 256, 180, 128, 64, 48, 32 and 16 px sizes where applicable.

## Brand colors

- Cobalt Blue: `#3155FF`
- Deep Charcoal: `#0F172A`
- Off-white: `#F8F9FB`
- White: `#FFFFFF`

## Typography

Wordmark direction: modern geometric grotesk / sans-serif. The supplied SVG uses `Inter Display` with semi-bold weight and tight tracking. The logo artwork itself contains no tagline.

## Clear-space / usage

Keep clear space around the symbol equal to at least the width of the narrowest inner negative-space channel. Never add shadows, gradients, bevels, outlines, texture, or decorative effects. Do not stretch the mark. Preserve the blue/charcoal relationship in the primary version.

Tagline for separate marketing copy only:

> Validate the idea first. Scale what works.
